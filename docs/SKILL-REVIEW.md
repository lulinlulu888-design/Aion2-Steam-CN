# v2.2.1 技能文本核查（2026-10-01）

用户反馈治愈星弱化之印、苦痛连锁、治愈气息、大地惩罚、破灭之语：名称为中文，正文和部分强化描述仍为英文。

## 原因

v2.2.0 内置载荷确实含有对应英文正文。台服参考表与 Global 存在机制和变量差异，旧合并程序在占位符不一致时采用备用文本，但备用文本仍可能是英文。旧报告中的 `english: 0` 不是可见英文残留数量，不能作为全游戏翻译完成的证据。

例如治愈气息的台服参考为召唤物、7m 范围；Global 是施法者增益和 40m 队伍范围。本次保留 Global 机制、距离和数值变量，不强行套用台服文本。

## 修复和检查

- 767 条八职业技能记录：正文、烙印/强化变体及方括号技能名称引用。五个反馈技能系列覆盖 75 条正文和强化/变体记录。
- 8 条独立状态提示：包括治愈气息的恢复、耐力、净化提示及杀星技能引用。
- 114 条玩家技能富文本标签：恢复 `<Unique>` / `<unique>` 与各自 Global 原文一致的大小写。
- 共修改 889 条记录；键集合、顺序和总数 152,629 不变，生成后解密回读与预期字典完全相同。
- 所有本次修改的玩家技能及指定状态记录，标签和变量多重集合与 Global 原文一致。人工句式回归检查确保占位符和字面数字不丢失、不新增。
- 生成器扫描八职业可见英文残留，若仍有未复核项则停止；打包脚本拒绝与源码声明哈希不符的载荷。

## 边界和已知待查项

本次没有游戏内实测，没有修改本机已安装的游戏文件。文本扫描通过不等于所有职业所有等级的运行时显示均已验证，也不能检测全部中文误译、单字母或双字母残留。

另有 1,827 条未按玩家职业分类的英文候选，包含 NPC、系统、测试/内部标记和其他异常状态记录，玩家可见性尚未逐条判定。输入载荷共有 228 条既有标签/占位符差异，本次修复其中 114 条玩家技能标签大小写；其余 114 条非玩家技能差异未自动改写，不能直接解释为全部都是变量损坏。

## 复现与更新

`python -m unittest discover -s tests -p test_skill_text_review.py` 运行翻译回归检查；`tests/run-updater-tests.ps1` 检查更新流程，加 `-Network` 验证 GitHub 正式附件下载与校验。

`tools/skill_text_review.py --help` 列出输入参数。需提供本地 `aion2_l10n_v2` 编解码模块、Global 原始语言文件、旧载荷和 manifest；这些材料不随源码发布。输出必须使用新路径。本地生成结果在 `bin/skills-review/L10NString.dat`，完整明细在 `bin/skills-review/report.json`，均不提交 Git。

工具版本 `2.2.1`，语言包版本 `2026.10.01.4`。v2.2.0 用户在工具内检查更新，完成重启后还需点击“安装 / 更新”，才会把新语言包应用到游戏。
