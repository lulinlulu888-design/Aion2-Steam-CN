# Aion2-Steam-CN v2.2.2

只需下载本页 Assets 中的 **Aion2-Steam-CN-v2.2.2.exe**。无需下载 Source code (zip) 或 Source code (tar.gz)，也无需另下语言包。

退出游戏后运行工具，点击“安装 / 更新”应用汉化。v2.2.0 及以上用户可先在旧工具内更新，重启后仍需点击“安装 / 更新”。

## 本次更新

- 适配 Steam 构建 25636629，保留原始英文 PAK 的严格哈希校验。本次英文文本与上一构建相比没有新增、删除或变更，容器哈希发生变化。
- 对照英文、韩文、日文、法文、德文和既有台服文本，复核八职业 13,215 条玩家技能记录及 244 条关联状态记录；这些包含名称、标签和变体，并非独立技能数量。
- 共修正 6,700 条记录，重点区分触发对象、触发概率、持续时间、恢复与吸收、伤害分担，以及“变为 1.5 倍”和“提高 150%”。
- 将容易误解为移动效果的“魔法位移”改为“魔力分担”，明确生命力与精神力承担伤害的含义；修复部分英文源文的对象、PvE/PvP 和重复恢复描述错误。
- 语言包版本：2026.10.01.5。

## 核查边界

仍有 9 条记录的源文没有明确吸收比例的计算基准、10 条记录含官方占位内容，译文保留相应提示，不编造机制。本次不代表全游戏文本完全无误，也未进行游戏内显示实测。

19 项文本测试、23 项离线更新器断言，以及隔离副本中的安装、模拟中断回滚、更新和还原测试通过。发布后使用已发布 v2.2.0 二进制通过真实 GitHub 检查、下载、校验、替换、保留备份及重启回调测试。未测试实际 UAC/GUI 重启，测试没有修改实际游戏目录。
