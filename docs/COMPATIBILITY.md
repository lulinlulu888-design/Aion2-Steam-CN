# 文本兼容安装（v2.4.0）

此改动不等于取消安全校验，也不等于游戏更新后自动翻译新增内容。

## 安装策略

- 已验证原始 PAK 哈希一致时，继续使用已验证的完整内置载荷。
- 文件哈希不一致时，读取当前原始 PAK，解密英文语言表，对每个键的当前源文计算 SHA-256，与内置基准源文指纹逐条比较。
- 只有键存在、源文完全一致、译文变量及标签集合一致时复用译文；新增或变化条目保留当前原文。删除条目不补回，顺序和容器前缀使用当前文件的值。
- 输出动态载荷后重新解码，检查全部键、值、顺序和前缀完全一致；写入后另做 SHA-256 校验。
- 有新增、变化或不安全条目时，安装前显示统计并要求确认。统计中的“复用”不等于所有条目均有中文；既有源文疑点和占位仍保留。
- 无可安全复用译文、格式/密钥变化、重复键、数据截断、正在更新、语言目录出现额外 PAK 或缺少当前原始包时停止，不绕过检查。

当前实现支持既有英文语言容器格式和密钥配置；格式或密钥变化仍可能需要更新工具。检查只覆盖此语言表，不保证其他游戏资源或机制兼容。

## 解包依赖

工具内嵌 [repak 0.2.3](https://github.com/trumank/repak/releases/tag/v0.2.3) 解包器及 MIT 许可。不依赖用户安装 Python，Python 仅用于维护者生成构建数据和独立测试。

新哈希的 Oodle 压缩 PAK 需要本地 `oo2core_9_win64.dll`：可放在工具旁的 `dependencies` 文件夹，或游戏 `Aion2/Binaries/Win64` 中。仅接受已验证组件哈希；程序不自动从第三方下载 DLL，不在仓库或发布安装包中重新分发 Oodle。缺少组件时新版本解包会停止；已验证版本的快速安装不需要该组件。

因此本版本并非“单个 EXE 离线适配所有未来更新”。语言数据变化时也不会自动译出新内容。

## 备份与更新

当前原始 PAK 优先于备份，不能用旧备份冒充新版原文。已安装工具标记存在时，只允许使用状态记录绑定且哈希一致、构建匹配的原始备份。

检测到新原始 PAK 时，将旧状态、备份和原有 loose DAT 分代保留于语言 PAK 目录的 `cn-history-*` 中，重新备份当前原始 PAK。若旧 loose DAT 的哈希等于旧安装状态载荷，不再将其当作新版“安装前原始数据”；新版还原时移除这个旧汉化文件，恢复新 PAK。

安装失败会回滚当前游戏文件并恢复原备份与状态。还原拒绝将旧 PAK 写到新原始 PAK 或不同构建上。历史目录保留，不自动删除。

## 从源码构建

基准数据和密钥只从维护者合法取得的本地文件生成，不提交源文本、密钥配置、语言载荷或构建数据到 Git。

```powershell
python tools/build_compatibility_reference.py --codec-dir C:\local\codec --manifest C:\local\key_manifest.dat --english C:\local\L10NString.dat --pak-key-source C:\local\key-config.cs --output bin\compatibility\reference.gz
.\build.ps1 -Payload C:\local\translated\L10NString.dat -CompatibilityData bin\compatibility\reference.gz -Repak C:\local\repak.exe -Output bin\v2.4.0\Aion2-Steam-CN-v2.4.0.exe
```

`key-config.cs` 提供既有本地配置的 `const string AesKey`（64 位十六进制字符串），不得提交到 Git。参考文件包含运行所需的密钥配置与源文指纹，因此构建产物也必须按既有发布授权范围处理，不应将密钥视作安装包中的秘密。

## 验证范围

实际英文加密容器回读、实际 Oodle PAK 解包、源文指纹匹配，以及合成新增/修改/删除、键顺序变化、新前缀、变量/标签不匹配、损坏容器和 LZ4 边界均有回归测试。

隔离文件测试覆盖已知版本安装和动态兼容安装、备份分代、分代过程中断恢复、更新中断回滚、还原新版原始 PAK，并拒绝旧备份覆盖新文件。UI 零尺寸绘制及更新器测试保留。实际游戏目录未修改，尚未游戏内显示实测。

正式发布后的旧版 v2.2.0 真实网络升级测试通过检测、下载、摘要校验、隔离替换、旧版备份保留及重启回调。首次下载网络超时，重试成功；未测试实际 UAC/GUI 重启，不配置 Oodle DLL，也不自动安装汉化。
