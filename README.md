# Aion2-Steam-CN

《永恒之塔2》Steam / Global 版简体中文本地化工具。

## 下载

**[下载 Aion2-Steam-CN v2.0 单文件安装版](./downloads/Aion2-Steam-CN-v2.0.exe?raw=1)**

无需解压，退出游戏后双击运行。完整说明、校验值和常见问题见 **[中文下载页](./DOWNLOAD.md)**。

版本变化见 **[更新记录](./CHANGELOG.md)**；机器可读的最新版本信息见 [`version.json`](./docs/version.json)。

项目以用户本机安装的台服官方繁体中文为主要参考源，转换为简体中文，并通过术语表统一《永恒之塔》系列的职业、技能、地图、属性与系统术语。

## 功能

- 自动读取 Steam 注册表和全部 Steam 库目录
- 自动规范化手工选择的 Steam 游戏目录
- Steam 客户端版本 SHA-256 兼容性检测
- 内置语言包完整性校验
- 游戏运行状态检测
- 一键安装或更新
- 自动备份原始 PAK 与既有语言文件
- 一键还原
- 文本条目数量、容器结构和占位符一致性校验
- 独立显示工具版本、语言包版本与支持的游戏构建
- 事务式安装/更新/还原，异常中断自动回滚
- 安装状态及备份 SHA-256 校验

## 当前兼容版本

当前工具只允许安装到已验证的全球版构建（152,629 条本地化文本）。游戏更新导致原始语言包哈希变化时，程序会拒绝覆盖，避免破坏客户端。

## 从源码构建

环境要求：Windows、.NET Framework 4.x。

出于版权与授权考虑，本仓库不包含游戏 PAK、官方文本、第三方汉化文本或预生成的 `L10NString.dat`。请使用自己合法安装的客户端在本地生成语言载荷，然后执行：

```powershell
.\build.ps1 -Payload 'C:\path\to\L10NString.dat'
```

输出文件默认位于 `bin\Aion2-Steam-CN.exe`。

## 使用提醒

1. 安装或还原前完全退出游戏。
2. 先点击“检测兼容性”。
3. 只有显示全球版构建完全匹配、优化包校验通过时才安装。
4. 如遇异常，立即使用“一键还原”。
