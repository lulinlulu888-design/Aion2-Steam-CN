# Aion2-Steam-CN｜永恒之塔2 Steam 汉化工具

《永恒之塔2》（AION 2 / AION2）Steam / Global 版汉化工具，提供简体中文汉化补丁下载、一键安装、更新、备份与还原。

## 永恒之塔2 汉化下载

**[前往 v2.4.0 正式 Release 下载页面](https://github.com/lulinlulu888-design/Aion2-Steam-CN/releases/tag/v2.4.0)**

**只需下载一个文件：`Aion2-Steam-CN-v2.4.0.exe`。** 在正式 Release 页面的 **Assets** 中点击该文件即可。

`Source code (zip)` 和 `Source code (tar.gz)` 是开发者使用的源码压缩包，普通用户无需下载。汉化数据已内置，无需另下语言包；退出游戏后双击 EXE 运行即可。

无需解压，退出游戏后双击运行。完整说明、校验值和常见问题见 **[中文下载页](./DOWNLOAD.md)**。

版本变化见 **[更新记录](./CHANGELOG.md)**；机器可读的最新版本信息见 [`version.json`](./docs/version.json)。

内置语言数据以台服官方繁体中文为主要参考源，转换为简体中文，并通过术语表统一《永恒之塔》国服惯用的职业、技能、地图、NPC、物品、属性与系统术语；最终用户无需安装台服客户端。

## 功能

- 自动读取 Steam 注册表和全部 Steam 库目录
- 自动规范化手工选择的 Steam 游戏目录
- 已验证 PAK 快速检测，以及未知哈希的源文键值、变量与容器兼容性检测
- 内置语言包完整性校验
- 游戏运行状态检测
- 一键安装或更新
- 自动备份原始 PAK 与既有语言文件
- 一键还原
- 文本条目数量、容器结构和占位符一致性校验
- 剧情对话 NPC 标题专项本地化与英文残留检查
- 对地图、剧情、NPC、物品、技能与系统文本执行国服术语残留检查
- 安装成功后显示醒目的绿色完成提示和确认窗口
- 独立显示工具版本、语言包版本与支持的游戏构建
- 事务式安装/更新/还原，异常中断自动回滚
- 安装状态及备份 SHA-256 校验

## 当前兼容版本

已验证的全球版构建（152,629 条本地化文本）使用快速安装；游戏语言 PAK 哈希变化时，v2.4.0 尝试逐条比较当前键及源文指纹，仅复用源文未变且变量/标签兼容的译文。变化、新增及不安全条目保留当前原文；格式、密钥或加载结构无法确认时停止。新哈希 Oodle PAK 检测需要本地合法取得且通过验证的 `oo2core_9_win64.dll`，放在工具旁的 `dependencies` 文件夹或游戏 `Aion2/Binaries/Win64` 中；发布包不包含、也不自动下载该组件。已验证构建的快速安装不需要它，工具自动更新也不会配置它。详见 [文本兼容说明](./docs/COMPATIBILITY.md)。

## 工具内更新（v2.2.0 起）

v2.2.0 起，工具启动时会在后台检查本仓库 GitHub Releases 的最新正式版本。有新版本时，点击“下载并更新工具”，确认后即可自动下载、校验、替换并重启。重启后再点击“安装 / 更新”应用汉化。下载失败或取消不会改变当前工具；离线仍可使用本地安装和还原功能。

旧版 v2.1.0 及更早版本没有更新功能，需要手动下载 v2.4.0 一次；以后可直接在工具内更新。

更新机制、发布要求和测试方法见 [自动更新说明](./docs/UPDATING.md)。

## 从源码构建

v2.4.0 新增按源文指纹逐条匹配的兼容安装，具体规则、解包依赖、备份分代及构建步骤见 [文本兼容说明](./docs/COMPATIBILITY.md)。

环境要求：Windows、.NET Framework 4.x。

出于版权与授权考虑，本仓库不包含游戏 PAK、官方文本、第三方汉化文本或预生成的 `L10NString.dat`。请使用自己合法安装的客户端在本地生成语言载荷，然后执行：

```powershell
.\build.ps1 -Payload 'C:\path\to\L10NString.dat'
```

输出文件默认位于 `bin\Aion2-Steam-CN.exe`。

## 使用提醒

1. 安装或还原前完全退出游戏。
2. 先点击“检测兼容性”。
3. 已验证构建走快速安装；未知哈希需完成文本兼容检测，并确认原文保留提示后安装。无法解码时不要强行覆盖。
4. 如遇异常，立即使用“一键还原”。
